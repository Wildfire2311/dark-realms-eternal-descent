# Dark Realms: Eternal Descent

A playable 2D isometric dark fantasy roguelite action RPG for PC, combining Diablo II presentation, classes, loot and progression with Vampire Survivors hordes and randomized level-up upgrades.

Play it here (GitHub Pages): https://wildfire2311.github.io/dark-realms-eternal-descent/

## Current build

v122 — toned-down Arcade 3 level-up sound, enemies ~1.33×, potions hard-capped at 3 per run.

## How to play

Open the link above in a browser. WASD to move, combat is fully automatic. Level up, pick weapons and passives, evolve them from boss chests, survive 30 minutes.
